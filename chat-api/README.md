# Portfolio AI guide

This is the server for the AI guide at `docs/ask/`. It answers from the public facts in `facts.mjs` and returns a small list of approved source links. The model receives no private CV, certificate, employer data, or local document. The answer is generated by Gemini; it may still make mistakes, so the interface asks visitors to check the linked pages.

## Local preview

Use Node.js 22 or later. Create a key for a **Free Tier** project in Google AI Studio and set `GEMINI_API_KEY` in your terminal environment. Run `npm run dev` here and open `http://localhost:4173/ask/`. Never paste the key into `docs/ask/config.js` or commit it. With no key, the page shows its disconnected state. Run `npm test` to check request handling without an API call.

## Public deployment

The portfolio remains on GitHub Pages. Deploy **this `chat-api` directory** as a Vercel project, using `chat-api` as the project root. Add `GEMINI_API_KEY` as a sensitive Production environment variable in Vercel Project Settings; optionally set `GEMINI_MODEL` (default: `gemini-3.5-flash-lite`). Once the `/api/chat` endpoint returns `{ "available": true }`, set `window.PORTFOLIO_CHAT_API` in `docs/ask/config.js` to the Vercel project origin (no trailing slash), and publish the site. Do not set that value until the endpoint is live. The deployed function permits browser requests from `https://om7203.github.io`.

Before exposing the endpoint publicly, configure platform-level request throttling. The endpoint validates input length and origin, but browser origin checks cannot stop direct scripted requests. Gemini Free Tier has rate limits; exceeding them can make the chat temporarily unavailable. Check the selected Google AI Studio project is on the Free Tier before deployment and do not link a billing account unless you intend to use the paid tier. Monitor usage and errors after launch. The server does not persist chat messages; it sends the latest question and up to four recent messages to the Gemini API. Google states that Free Tier prompts may be used to improve its products, so the chat warns visitors not to share sensitive information.

To update answers, edit `facts.mjs` only after the corresponding public page is up to date. Keep employer-private information out of this file.
